# Method — Shadow model attack

## Definition

A technique for training a [[Concept — Membership inference]] attack classifier without ever knowing the true training-set membership of the actual target model's data.
The attacker trains several **shadow models**, each on its own dataset in the same format and (ideally) drawn from a similar distribution as the target's training data, using the same platform or architecture family as the target where possible.
Because the attacker chose the shadow training data themselves, they know exactly which records each shadow model saw during training ("in") and which it didn't ("out") - ground truth unavailable for the real target model, which is exactly the problem this technique sidesteps.
Querying each shadow model on both its own training records and disjoint held-out records produces a labeled dataset of (prediction vector, true label, in/out) examples, which supervises an ordinary binary classifier - the **attack model** - to distinguish "in" behavior from "out" behavior.
This same, already-trained attack model is then queried on the real target model's prediction for whatever record is under investigation.

## Why it works

The technique only requires that shadow models behave *similarly enough* to the target model that patterns the attack model learns on shadow data transfer to the real target - it never requires the shadow models to be identical to the target, or even architecturally similar, since the attack model is trained on the abstract shape of prediction-vector behavior rather than on any model-specific detail.
[[Paper — Membership Inference Attacks Against Machine Learning Models (2017)]] shows this holds even when shadow training data is entirely synthetic, generated by a hill-climbing search against the target model itself with no real or statistically-representative data used at all - evidence the technique is robust to substantial mismatch between shadow and target training distributions, not merely tolerant of small differences.

## Relations

- Introduced by [[Paper — Membership Inference Attacks Against Machine Learning Models (2017)]] as the technique that makes [[Concept — Membership inference]] practical against genuinely black-box models.
- A general pattern - train a surrogate to generate the labeled data you actually need but don't have - that recurs well beyond membership inference specifically.
